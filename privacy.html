Privacy Policy

Last updated: 2026-09-30

  • Who uses it: Only the owner of this tool. It is not offered to anyone else.
  • What data: Data in the owner's own Google account, accessed only when the owner asks for it.
  • Where it goes: The data is handled on the owner's own computer. It may be processed by the AI assistant service the owner chooses to use, as part of the owner's own requests. This tool does not run any server of its own.
  • Storage: Access tokens are stored only on the owner's computer.
  • Sharing: The data is not sold, not used for advertising, and not shared with anyone else.
  • Revoking access: Access can be removed at any time from Google Account > Security > Third-party apps & services.

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

プライバシーポリシー

  • 使う人: このツールの所有者本人だけです。他の人には提供していません。
  • 扱うデータ: 所有者自身のGoogleアカウントのデータを、所有者が頼んだときだけ読み書きします。
  • データの行き先: 所有者のパソコン上で扱います。所有者が頼んだ作業の一部として、所有者が選んだAIアシスタントのサービスが処理することがあります。このツール自体はサーバーを持ちません。
  • 保存: 認証の情報は所有者のパソコンの中にだけ保存します。
  • 共有: データを売ったり、広告に使ったり、他の人に渡したりはしません。
  • 取り消し: Googleアカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」から、いつでも取り消せます。
